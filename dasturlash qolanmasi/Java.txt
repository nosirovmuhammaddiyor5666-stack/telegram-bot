# Java Dasturlash Tili Bo'yicha Qisqacha Qo'llanma

Java - obyektga yo'naltirilgan, platformadan mustaqil (JVM) va yirik korporativ ilovalar yaratishda ishlatiladigan til.

## 1. Asosiy tuzilma ("Hello, World!")
```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Salom, Dunyo!");
    }
}
```

## 2. O'zgaruvchilar va Ma'lumot turlari
```java
int yosh = 20;
double narx = 19.99;
String ism = "Ali";
boolean isActive = true;
```

## 3. Shart operatorlari (if-else)
```java
int son = 10;
if (son > 0) {
    System.out.println("Musbat son");
} else {
    System.out.println("Manfiy son");
}
```

## 4. Takrorlash operatorlari (Loops)
```java
for (int i = 0; i < 5; i++) {
    System.out.println(i);
}
```
